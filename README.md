# 📝 Notes App

A simple and responsive **Notes App** built using **HTML, CSS, and JavaScript**.  
This app allows users to **create, edit, and delete notes** directly in their browser using the `localStorage` feature — so notes remain saved even after refreshing the page.

---

## 🚀 Features
- ✍️ **Add Notes** – Write and save your ideas instantly.  
- 🖊️ **Edit Notes** – Update existing notes easily.  
- 🗑️ **Delete Notes** – Remove unwanted notes in one click.  
- 💾 **Persistent Storage** – Uses `localStorage` to save notes.  
- 🎨 **Clean UI** – Simple and responsive design using CSS.

---

## 🧠 What You’ll Learn
- DOM manipulation with JavaScript  
- Using `localStorage` for persistent data  
- Basic CRUD operations (Create, Read, Update, Delete)  
- HTML and CSS layout design

---

## 🛠️ Technologies Used
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**
